Privacy Policy — BuildVerse

Last updated: October 20, 2026 · Developer: Shaheen Company · Contact: turky.jadou@gmail.com

BuildVerse is a creative block-building game designed for children (ages 6 and up) and families. This policy explains, in simple words, what information the game uses, when, and why. By using the game you agree to this policy.

1. The short version

  • There are no accounts and no sign-up. We never ask for a real name, email address, phone number, or date of birth.
  • The game works fully offline for single-player building.
  • Online features (sharing a world, live multiplayer) are optional and only activate when the player explicitly chooses them.
  • We do not sell data, we run no advertising in the current version, and we use no analytics or tracking tools.

2. Information stored on your device only

The following never leaves the device and is deleted when you delete the game or clear its data:

  • Worlds the player builds, and their names.
  • Game progress: diamonds, stars, gifts, and items owned in the in-game shop.
  • Settings: language, sound, music, and control preferences.
  • The display name the player types in (see Section 3).

3. The display name

Players choose a display name inside the game (for example "Builder Sam"). It can be any nickname — please do not use a child's real full name. This name is stored on the device and is only shown to other players during a live multiplayer session the player joined (Section 5).

4. Optional feature: sharing a world

When a player taps "Share world", the world data (block layout and world name) is uploaded to our cloud database (Google Firebase Realtime Database) and the player receives a short code. Anyone who enters that code can download a copy of that world. Sharing is never automatic; nothing is uploaded unless the player chooses to share. A parent or guardian may ask us to delete a shared world at any time by emailing us with the share code.

5. Optional feature: live multiplayer

When a player creates or joins a live session using a session code, the following data is exchanged through Google Firebase Realtime Database only while the session is active:

  • The chosen display name (nickname), shown above the player's character.
  • The character's position in the world, so players can see each other.
  • Block building/breaking actions, so players see the world change together.

There is no chat (text, voice, or images) between players, no friend lists, and no way for strangers to find or contact a player. Sessions are joined only by entering a code shared between people who know each other. Session data is transient: it is removed when the session ends and is not used for any other purpose.

6. Permissions the game uses

  • Internet access — only for the optional online features above and to check for game updates.
  • The game does not request location, camera, microphone, contacts, photos, or storage access.

7. Children's privacy

BuildVerse is designed for children and follows the principles of the U.S. Children's Online Privacy Protection Act (COPPA) and similar laws:

  • We do not knowingly collect personal information from children. The only identifier used online is a player-chosen nickname during an optional live session.
  • No advertising, no behavioral tracking, no profiling.
  • In-app purchases, when offered in the future, will always be protected by a parental gate and processed by Google Play; we never see or store payment card details.
  • Parents or guardians can contact us at turky.jadou@gmail.com to review or request deletion of any data associated with a share code or session, or to ask any question about this policy.

8. Third-party services

The game uses Google Firebase Realtime Database solely to power the optional sharing and multiplayer features described above. Google processes this data as described in Google's own privacy documentation. The game contains no other third-party data services, no advertising networks, and no analytics providers.

9. Data security and retention

Data is transferred over encrypted connections (HTTPS/WSS). Shared worlds are kept until the owner or a parent asks us to remove them, or until we periodically clean up inactive shared data. Live session data exists only for the duration of the session. Because players provide no accounts or personal identifiers, most data in the game cannot be linked to a specific person.

10. Changes to this policy

If we change this policy — for example, if we add features that use data in a new way — we will update this page and change the "Last updated" date above before the change takes effect in the game.

سياسة الخصوصية — BuildVerse (ابنِ عالمك)

آخر تحديث: 20 أكتوبر 2026 · المطوّر: Shaheen Company · للتواصل: turky.jadou@gmail.com

لعبة BuildVerse لعبة بناء إبداعية بالمكعبات مصممة للأطفال (من عمر 6 سنوات) والعائلات. توضح هذه السياسة بلغة بسيطة ما المعلومات التي تستخدمها اللعبة ومتى ولماذا. باستخدامك اللعبة فأنت توافق على هذه السياسة.

1. الخلاصة

  • لا توجد حسابات ولا تسجيل — لا نطلب أبداً اسماً حقيقياً أو بريداً إلكترونياً أو رقم هاتف أو تاريخ ميلاد.
  • اللعبة تعمل دون إنترنت بالكامل في اللعب الفردي والبناء.
  • المزايا عبر الإنترنت (مشاركة عالم، لعب جماعي حي) اختيارية ولا تعمل إلا عندما يختارها اللاعب بنفسه.
  • لا نبيع أي بيانات، ولا توجد إعلانات في النسخة الحالية، ولا نستخدم أي أدوات تتبع أو تحليلات.

2. معلومات تبقى على جهازك فقط

المعلومات التالية لا تغادر الجهاز أبداً، وتُحذف بحذف اللعبة أو مسح بياناتها:

  • العوالم التي يبنيها اللاعب وأسماؤها.
  • تقدم اللعب: الماسات والنجوم والهدايا والعناصر المملوكة في متجر اللعبة.
  • الإعدادات: اللغة والصوت والموسيقى وتفضيلات التحكم.
  • اسم العرض الذي يكتبه اللاعب داخل اللعبة (البند 3).

3. اسم العرض

يختار اللاعب اسم عرض داخل اللعبة (مثل: «البنّاء سامي»)، ويمكن أن يكون أي لقب — نرجو عدم استخدام الاسم الحقيقي الكامل للطفل. يُحفظ هذا الاسم على الجهاز، ولا يظهر للاعبين آخرين إلا أثناء جلسة لعب جماعي حي انضم إليها اللاعب (البند 5).

4. ميزة اختيارية: مشاركة عالم

عندما يضغط اللاعب «مشاركة العالم»، تُرفع بيانات العالم (توزيع المكعبات واسم العالم) إلى قاعدة بياناتنا السحابية (Google Firebase Realtime Database) ويحصل اللاعب على كود قصير. أي شخص يدخل هذا الكود يستطيع تنزيل نسخة من ذلك العالم. المشاركة لا تتم أبداً تلقائياً؛ لا يُرفع أي شيء إلا باختيار اللاعب. ويمكن لولي الأمر طلب حذف أي عالم مُشارك في أي وقت عبر مراسلتنا مع ذكر كود المشاركة.

5. ميزة اختيارية: اللعب الجماعي الحي

عندما ينشئ اللاعب جلسة حية أو ينضم إليها بكود جلسة، تتبادل اللعبة البيانات التالية عبر Google Firebase Realtime Database أثناء الجلسة فقط:

  • اسم العرض (اللقب) المختار، ليظهر فوق شخصية اللاعب.
  • موضع الشخصية داخل العالم، ليرى اللاعبون بعضهم بعضاً.
  • أفعال بناء المكعبات وكسرها، ليرى الجميع تغيّر العالم معاً.

لا توجد أي دردشة (نصية أو صوتية أو صور) بين اللاعبين، ولا قوائم أصدقاء، ولا أي وسيلة لتواصل الغرباء مع اللاعب أو العثور عليه. الدخول إلى الجلسات يكون فقط بكود يتبادله أشخاص يعرفون بعضهم. بيانات الجلسة مؤقتة: تُزال عند انتهاء الجلسة ولا تُستخدم لأي غرض آخر.

6. الأذونات التي تستخدمها اللعبة

  • الوصول إلى الإنترنت — فقط للمزايا الاختيارية أعلاه وللتحقق من تحديثات اللعبة.
  • اللعبة لا تطلب الموقع ولا الكاميرا ولا الميكروفون ولا جهات الاتصال ولا الصور ولا التخزين.

7. خصوصية الأطفال

اللعبة مصممة للأطفال وتلتزم بمبادئ قانون حماية خصوصية الأطفال الأمريكي (COPPA) والقوانين المشابهة:

  • لا نجمع عن قصد أي معلومات شخصية من الأطفال. المعرف الوحيد المستخدم عبر الإنترنت هو لقب يختاره اللاعب أثناء جلسة اختيارية.
  • لا إعلانات، ولا تتبع سلوكي، ولا ملفات تعريف للمستخدمين.
  • المشتريات داخل التطبيق — عند تقديمها مستقبلاً — ستكون محمية دائماً بـ«بوابة أهل» وتُعالج عبر Google Play؛ لن نرى أو نخزن أي بيانات بطاقات دفع أبداً.
  • يمكن للأهل أو الأوصياء التواصل معنا عبر turky.jadou@gmail.com لمراجعة أو طلب حذف أي بيانات مرتبطة بكود مشاركة أو جلسة، أو لطرح أي سؤال حول هذه السياسة.

8. خدمات الطرف الثالث

تستخدم اللعبة Google Firebase Realtime Database فقط لتشغيل ميزتي المشاركة واللعب الجماعي الاختياريتين الموضّحتين أعلاه، وتعالج Google هذه البيانات وفق وثائق الخصوصية الخاصة بها. لا تحتوي اللعبة على أي خدمات بيانات خارجية أخرى، ولا شبكات إعلانات، ولا مزوّدي تحليلات.

9. أمان البيانات والاحتفاظ بها

تُنقل البيانات عبر اتصالات مشفرة (HTTPS/WSS). تُحفظ العوالم المُشاركة حتى يطلب مالكها أو ولي أمر إزالتها، أو حتى نقوم بتنظيف دوري للبيانات غير النشطة. بيانات الجلسات الحية موجودة فقط لمدة الجلسة. وبما أن اللاعبين لا يقدمون حسابات أو معرّفات شخصية، فإن معظم بيانات اللعبة لا يمكن ربطها بشخص محدد.
